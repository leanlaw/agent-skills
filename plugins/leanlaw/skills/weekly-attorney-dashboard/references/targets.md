# Billable-hour targets

The LeanLaw connector has no target field, so a firm that wants targets in the dashboard
records them here. Edit your installed copy of this file; leave it empty to run without
targets.

Match on email. `period` is `week`, `month` or `year`. Set `includes_fixed_fee` to `yes`
if time on fixed-fee matters counts toward the target at your firm.

| email | target_hours | period | includes_fixed_fee |
|---|---|---|---|

Example row, not used:

`| dana@example.com | 1800 | year | no |`
